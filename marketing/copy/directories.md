## Short description (≤ 160 characters)
> A notebook-style journal that saves every entry to one plain markdown file you own. No account, no subscription.

## Long description (≤ 1,000 characters)
> Daycell is a daily journal that looks like a code notebook. Each entry is a cell; there's a prompt every day, a
> streak and activity grid, mood and tag insights, search and a command palette.
>
> Your whole journal is one plain markdown file on your device, so you can open it in any editor, keep it in Obsidian,
> back it up anywhere, or put it in git. There's no account and nothing is uploaded. The code is public.
>
> Writing is free forever. Pro is a one-time £12 for [Pro features as shipped].
